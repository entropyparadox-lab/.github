## 🏛️ 使命与工程哲学

EntropyParadox Lab 专注于构建高密度、确定性系统与开发者底层工具。我们消除抽象层开销，深耕两大核心领域：

1. **确定性 AI Agent 运行时**：为自主编码 Agent 构建微秒级执行 Harness、沙箱环境及自愈动作缓存。
2. **纯 Zig (v0.16.0+) 生态原语**：打造无外部依赖、零堆内存分配（`0-Alloc`）、编译期验证的系统组件。

---

## 🚀 核心开源项目

* **[`web-reflex`](https://github.com/entropyparadox-lab/web-reflex)**：面向 AI Web Agent 的确定性即时（<45ms）自愈动作缓存。
* **[`mos`](https://github.com/entropyparadox-lab/mos)**：基于 Linux KVM 与 Firecracker MicroVM 的超轻量 Scale-to-Zero Serverless PaaS。
* **[`zig-doc-engine`](https://github.com/entropyparadox-lab/zig-doc-engine)**：小于 550KB 的极速离线 FTS5 文档索引与检索引擎，保障 LLM 编译零错误。
* **[`zmcp`](https://github.com/entropyparadox-lab/zmcp)** & **[`zmcp-gateway`](https://github.com/entropyparadox-lab/zmcp-gateway)**：纯 Zig 实现的高性能 Model Context Protocol (MCP) SDK 与工具网关。
