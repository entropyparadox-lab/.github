# Security Policy

## Supported Versions

EntropyParadox Lab actively maintains security patches for the latest minor and patch releases across our core repositories.

| Project | Supported Versions |
| :--- | :--- |
| `zig-doc-engine` | `v1.3.x` |
| `web-reflex` | `v1.0.x` |
| `mos` | `v0.2.x` |
| `zmcp` & `zmcp-gateway` | `v0.1.x` |

---

## Reporting a Vulnerability

If you discover a security vulnerability within any EntropyParadox Lab repository:

1. **Do NOT disclose it publicly** in issues, PRs, or public chat channels.
2. Please report the vulnerability privately via **GitHub Security Advisories** on the relevant repository, or email `security@entropyparadox.com`.
3. Provide detailed steps to reproduce, impact analysis, and proof-of-concept if available.

We commit to acknowledging your report within **48 hours** and providing regular status updates until the vulnerability is addressed.
